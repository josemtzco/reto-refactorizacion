## Diagnóstico

Sin modificar archivos, haz una auditoría de calidad de src/. Devuélvela como una tabla con estas columnas: # | archivo:función | code smell | severidad (alta/media/baja) | refactorización propuesta | riesgo para los tests. Ordénala por severidad. Al final, propón un orden de ejecución que minimice el riesgo de romper tests y justifícalo.
